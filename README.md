# Navya Thottempudi — SWE Portfolio

A professional, recruiter-focused portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Build

```bash
npm run build
npm run preview
```

## Before deploying

1. Add a real profile photo if you want one.
2. Replace the placeholder GitHub links for projects where the resume does not provide a dedicated repository.
3. Add a PDF resume to `public/resume.pdf` and add a "Download Resume" button if desired.
4. Verify every project link and live demo.
5. Deploy to Vercel or Netlify.

## Stack

- React
- Vite
- Lucide React
- CSS (responsive, no UI framework dependency)
